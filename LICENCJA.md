# Licencja

Security Audit, wersja 1.0.0. Autor: Bartek Filipiuk.

Możesz używać tego skilla bez ograniczeń: we własnych projektach, w pracy i w projektach klientów,
na dowolnej liczbie projektów i maszyn, oraz modyfikować go na własne potrzeby.

Nie możesz odsprzedawać, publikować ani udostępniać plików skilla (w oryginale ani w zmienionej
postaci) osobom, które go nie kupiły.

Skill jest narzędziem do przeglądu kodu, a nie gwarancją bezpieczeństwa. Dostarczany jest
„tak jak jest”, bez gwarancji. Brak znalezisk nie oznacza braku podatności.
